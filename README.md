# guitar-hero
Jogo do Guitar Hero criado para a aula de Linguagens de Programação do curso de Sistemas de Informação da Universidade Católica de Santos

# Como clonar?
Com o git instalado na máquina (para verificar, basta abrir o terminal e inserir o comando "git --version". Caso o comando não retornar a versão instalada do git, será preciso instalá-lo antes), clique no botão verde "Clone" na página do repositório e copie a URL HTTPS. Novamente no terminal, insira o comando "git clone <URL>", substituindo <URL> pelo link copiado do repositório.

# Como abrir o jogo?
Uma vez clonado, abra a pasta gerada e, em seguida, dê dois cliques no arquivo "index.html". Ligue o som e aproveite! ✌️🍁😎

# Como jogar?
Por hora, o jogo contempla apenas o modo fácil de uma única música. As teclas disponíveis são A, S e J para os botões verde, vermelho e amarelo, respectivamente.
